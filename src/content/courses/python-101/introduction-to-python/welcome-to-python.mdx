# Welcome to Python

Meet Python, run your first programs, and learn how to debug with confidence. In this lesson, you will focus on **welcome to python** and connect the idea to a small program.

## Learning objectives

- Explain the central idea in your own words.
- Read and modify a short Python example.
- Practice the idea with a small experiment.

```python-executable title="Try it yourself"
print("Welcome to Python is a great place to start!")
```

## Practice

Change one value in the example, run it again, and describe what changed. If Python shows an error, read the final line first and fix one thing at a time.

## Summary

You now have a working mental model for welcome to python. Keep the example nearby as a reference while you continue through the module.
