# For loops

Make decisions and repeat work with conditions and loops. In this lesson, you will focus on **for loops** and connect the idea to a small program.

## Learning objectives

- Explain the central idea in your own words.
- Read and modify a short Python example.
- Practice the idea with a small experiment.

```python-executable title="Try it yourself"
for step in range(3):
    print("For loops step", step + 1)
```

## Practice

Change one value in the example, run it again, and describe what changed. If Python shows an error, read the final line first and fix one thing at a time.

## Summary

You now have a working mental model for for loops. Keep the example nearby as a reference while you continue through the module.
