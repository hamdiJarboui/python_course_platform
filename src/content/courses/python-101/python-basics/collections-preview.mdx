# A first look at collections

Lists keep an ordered group of values. Dictionaries connect descriptive keys to values.

```python-executable title="A learner profile"
topics = ["variables", "strings", "lists"]
profile = {"name": "Learner", "topics": len(topics)}
print(topics[0])
print(profile["name"], "is exploring", profile["topics"], "topics")
```

Collections make it possible to represent richer information without creating a separate variable for every item.
