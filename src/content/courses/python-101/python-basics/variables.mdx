# Variables and names

A variable is a name that points to a value. Choose names that describe what the value means.

```python-executable title="A reusable value"
hours = 3
lessons = 6
print("Total practice minutes:", hours * 60)
print("Lessons remaining:", lessons)
```

Assignment uses `=`. It does not mean “is equal to” in the mathematical sense; it tells Python to remember a value under a name.
