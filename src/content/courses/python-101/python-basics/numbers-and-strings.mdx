# Numbers and strings

Python includes integers and decimal numbers, as well as strings of text. Operators let you calculate and combine them.

```python-executable title="A tiny receipt"
price = 12.5
quantity = 3
label = "notebook"
print(label, "total:", price * quantity)
```

Use `str()` when a number needs to become text, and `round()` when a result needs a predictable number of decimal places.
